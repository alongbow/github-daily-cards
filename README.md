# github-daily-cards

复制链接 → 发给 AI 助手 → 说出日榜。

仓库：https://github.com/alongbow/github-daily-cards

## 怎么用（就两句半）

1. 把本仓库链接发给**带「装扩展 / 装技能」功能**的 AI 助手（带「装扩展 / 装技能」功能即可）。
2. 说：`帮我装上这套做日榜卡片的说明书`（它自己读 `SKILL.md`、自己装）。
3. 再说：`做一份 GitHub 日榜`。

诚实说明：说明书教助手怎么干；本机还要有一份「做卡片的程序」负责把图画出来（`render.py` 那套）。没有的话让助手按说明书帮你准备；默认目录名 `xhs-github-daily`。

没有能装技能的助手，这份 skill 暂时帮不了你。

## 亮点

- 不限定哪一家 AI
- 白话简介（先讲是啥能干嘛）
- 可走外行读者审稿
- 排版硬约束，字不叠
